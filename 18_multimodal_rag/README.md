# 18 — PDF and Multimodal RAG

Load PDF documents for RAG and use multimodal prompting with images.

## What You'll Learn

- Extract and chunk text from PDF documents
- Build a RAG pipeline over PDF content with page-level source tracking
- Send image + text prompts to vision-capable models

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
