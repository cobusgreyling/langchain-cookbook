# 10 — Local LLM with Ollama

Run LangChain entirely locally using Ollama — no API keys needed.

## Prerequisites

1. Install [Ollama](https://ollama.com)
2. Pull a model: `ollama pull llama3.2`

## What You'll Learn

- Connect LangChain to a local Ollama model
- Run chains and agents without any cloud API
- Use local embeddings for RAG

## Run

```bash
# No API key needed!
python main.py
```
