# 33 — Text-to-SQL Agent

Convert natural language questions into SQL queries and summarise results.

## What You'll Learn

- Set up an in-memory SQLite database with sample data
- Build a tool-calling agent that generates and executes SQL
- Enforce read-only access for safety
- Handle SQL errors with self-correction

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
