# 32 — RAG Evaluation with RAGAS-style Metrics

Systematically evaluate a RAG pipeline with faithfulness, relevance, and correctness metrics.

## What You'll Learn

- Create a test dataset with ground truth answers
- Implement LLM-as-judge evaluation for three key metrics
- Measure faithfulness (hallucination detection), relevance, and correctness
- Generate a structured evaluation report

export OPENAI_API_KEY="your-key"
