# 29 — Human-in-the-Loop with LangGraph

An agent that pauses for human approval before executing sensitive actions.

## What You'll Learn

- Classify tool calls as sensitive or safe
- Pause agent execution for human review
- Route between approval and denial paths in LangGraph
- Use checkpointing to resume after human input

## Run

```bash
export OPENAI_API_KEY="your-key"
```
