# 03 — Structured Output Parsing

Extract structured data from unstructured text using Pydantic models and LangChain's `with_structured_output`.

## What You'll Learn

- Define output schemas with Pydantic
- Use `with_structured_output` for reliable parsing
- Handle nested and complex data structures

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
