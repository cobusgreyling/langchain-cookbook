# 13 — Modern Tool Calling

Native function/tool calling with LLMs — bind tools, handle parallel tool calls, and synthesise results.

## What You'll Learn

- Bind tools to a chat model with `bind_tools()`
- Handle multi-tool invocations in a single turn
- Execute tool calls and feed results back to the LLM

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
