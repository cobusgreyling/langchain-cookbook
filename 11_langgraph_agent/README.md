# 11 — LangGraph Agent

Build a stateful, graph-based agent using LangGraph with conditional routing and checkpointing.

## What You'll Learn

- Define a `StateGraph` with typed state
- Create nodes for LLM reasoning and tool execution
- Use conditional edges to route between nodes
- Persist conversation state with `MemorySaver`

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
