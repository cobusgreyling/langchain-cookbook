# 16 — Callbacks and Observability

Monitor LangChain chains with custom callback handlers for logging, token counting, and cost tracking.

## What You'll Learn

- Build a custom `BaseCallbackHandler` for tracing
- Track token usage, latency, and estimated cost
- Attach callbacks to chains and LLMs

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
