# 17 — Output Guardrails and Moderation

Validate, filter, and moderate LLM outputs before they reach users.

## What You'll Learn

- Detect and redact PII (emails, phone numbers, SSNs, credit cards)
- Use an LLM as a content moderator
- Validate output quality and retry on low confidence

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
