# 25 — Async Execution

Run LangChain chains concurrently for better throughput with async/await.

## What You'll Learn

- Compare sync vs async chain invocation
- Process batches concurrently with `asyncio.gather`
- Stream tokens asynchronously
- Run multiple different chains in parallel

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
