# 26 — Graph RAG (Knowledge Graphs)

Combine vector retrieval with a knowledge graph for richer, relationship-aware answers.

## What You'll Learn

- Extract entities and relationships from documents using structured output
- Build an in-memory knowledge graph with adjacency lists
- Merge vector similarity results with graph traversal context
- Answer questions that require understanding relationships between concepts

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
