# 27 — Agentic RAG

An agent that decides when and how to retrieve, with query rewriting and relevance grading.

## What You'll Learn

- Rewrite vague questions into search-friendly queries
- Grade retrieved documents for relevance
- Build a retrieve → grade → re-query loop with LangGraph
- Implement self-correcting retrieval with a maximum attempt limit

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
