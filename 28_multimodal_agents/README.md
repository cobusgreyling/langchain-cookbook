# 28 — Multi-Modal Agents (Vision + Tools)

An agent that reasons over visual input and calls tools based on what it sees.

## What You'll Learn

- Build a vision-capable agent with tool calling
- Combine image analysis with structured tool use
- Route between analysis and action in a LangGraph loop

export OPENAI_API_KEY="your-key"
