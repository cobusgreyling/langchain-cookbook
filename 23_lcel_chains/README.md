# 23 — LCEL (LangChain Expression Language)

Compose chains declaratively using pipes, parallel execution, branching, and lambda transforms.

## What You'll Learn

- Chain components with the `|` pipe operator
- Run chains in parallel with `RunnableParallel`
- Route inputs with `RunnableBranch`
- Add custom logic with `RunnableLambda`

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
