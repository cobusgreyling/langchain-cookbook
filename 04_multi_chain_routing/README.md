# 04 — Multi-Chain Routing

Route user queries to specialized chains based on the topic, using an LLM-based classifier.

## What You'll Learn

- Build topic-specific chains with different prompts
- Use an LLM to classify and route queries
- Compose chains using LangChain Expression Language (LCEL)

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
