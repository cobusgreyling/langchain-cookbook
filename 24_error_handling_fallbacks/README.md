# 24 — Error Handling and Fallbacks

Build resilient LLM applications with retries, model fallbacks, and graceful degradation.

## What You'll Learn

- Configure automatic retries with backoff on LLM calls
- Chain model fallbacks (primary model → backup model)
- Implement graceful degradation with default responses
- Build custom retry logic with exponential backoff

## Run

```bash
export OPENAI_API_KEY="your-key"
python main.py
```
